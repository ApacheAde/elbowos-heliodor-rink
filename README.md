# Heliodor Rink

Full-colour Python 3 neon air-hockey arcade for [ElbowOS](https://x.com/ElbowOS).

Slam a cyan puck with a gold heliodor mallet. A magenta CPU guards the far crease.
WASD or arrows steer. R resets.

## Play

```
pip install -r requirements.txt
python3 heliodor_rink.py
```

## Record a 9:16 reel

```
python3 heliodor_rink.py --record
```
